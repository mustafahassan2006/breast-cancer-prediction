# Breast Cancer Prediction using Machine Learning

## Overview

This project builds a Machine Learning model to classify breast cancer tumors as **Benign** or **Malignant** using the Wisconsin Breast Cancer Dataset.

The notebook demonstrates a complete ML workflow, including:

- Data loading
- Data preprocessing
- Exploratory Data Analysis (EDA)
- Feature scaling
- Model training
- Model evaluation
- Prediction on unseen data

---

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

---

## Machine Learning Workflow

1. Load Dataset
2. Clean and Prepare Data
3. Split Training/Test Data
4. Scale Features
5. Train Classification Model
6. Evaluate Performance
7. Make Predictions

---

## Dataset

Wisconsin Breast Cancer Dataset

---

## Results

The trained model successfully classifies tumors as Benign or Malignant with high accuracy.
